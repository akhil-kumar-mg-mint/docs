---
title: 'Trigger Recurring Payment'
description: 'Trigger a recurring payment for an ADHOC subscription.'
api: 'POST /pg/subscriptions/{subscription_id}/recurring_payment/'
---

Trigger a charge on an active **ADHOC** subscription. The call initiates the payment — the outcome (success, failure, or cancellation) arrives asynchronously by webhook, and the order and payment records are created at that point.

<Info>
This endpoint only supports **ADHOC** subscriptions. The subscription must have an active mandate before a recurring payment can be triggered — check it with [Get Subscription Mandate Status](/api-reference/v3/subscriptions/mandate-status).
</Info>

<Info>
A `409` means the subscription's own state refused the charge — there is no active pre-debit notification for today, or a charge is already in progress. A `400` means the amount is above the billing amount or above the pre-debit notified amount. In both cases nothing reached the bank: fix the cause, then call again. A `502` means the payment network failed.
</Info>

<Info>
**What applies depends on the subscription's payment method.**

- **Methods that use a pre-debit notification**: `invoice_display_number` is required (use the value sent in the pre-debit notification); `transaction_id` is optional. The charge needs an active pre-debit notification for today, so the `409` for a missing pre-debit and the `400` for an amount above the pre-debit amount apply here only. The response `data` is `{ "order_id", "status", "message" }`. It can return `202` when the debit was accepted but the bank outcome is still pending, and a failed debit returns `400` with `{ "error": "<reason>" }` in `details`.
- **Other methods**: `invoice_display_number` is not required and `amount` is ignored for the charge. A `409` is returned when a charge is already initiated for tomorrow, the day the debit happens.
</Info>

### Path Parameters

<ParamField path="subscription_id" type="string" required>
  The unique identifier (uid) of the subscription.
</ParamField>

### Request Body

<ParamField body="amount" type="number">
  Amount to charge for this execution. Defaults to the subscription's `billing_amount`, and must not exceed it. For methods that use a pre-debit notification it must also not exceed the pre-debit notified amount; other methods ignore it.
</ParamField>

<ParamField body="invoice_display_number" type="string">
  Your display number for this charge. Required for methods that use a pre-debit notification; not needed otherwise.
</ParamField>

<ParamField body="transaction_id" type="string">
  Optional unique transaction ID (max 64 characters). A `REC-` prefixed ID is generated when omitted.
</ParamField>

### Response Fields

<ResponseField name="subscription_id" type="string">
  The subscription identifier.
</ResponseField>

<ResponseField name="payment_id" type="string">
  Auto-generated with a `REC-` prefix if not provided.
</ResponseField>

<ResponseField name="payment_amount" type="number">
  The amount charged for this recurring payment.
</ResponseField>

<ResponseField name="status" type="string">
  Status of the API call. `success` means the payment was initiated — not that it has been captured.
</ResponseField>

<ResponseExample>
```json 200 - Payment initiated
{
  "success": true,
  "message": "Recurring payment triggered successfully",
  "data": {
    "subscription_id": "SUB7989707770",
    "payment_id": "REC-SUB7989707770-a1b2c3d4",
    "payment_amount": 500.00,
    "status": "success",
    "message": "ADHOC recurring payment initiated successfully"
  }
}
```

```json 400 - Amount exceeds billing amount
{
  "success": false,
  "error": {
    "code": "ERR_PAYMENT_001",
    "message": "Validation error",
    "details": {
      "amount": "Recurring amount must be less than or equal to the subscription billing amount"
    }
  }
}
```

```json 409 - Charge refused
{
  "success": false,
  "error": {
    "code": "ERR_PAYMENT_001",
    "message": "Validation error",
    "details": {
      "recurring": "A recurring charge is already in progress for this subscription; wait for it to complete before initiating another."
    }
  }
}
```

```json 502 - API error
{
  "success": false,
  "error": {
    "code": "ERR_PAYMENT_003",
    "message": "API error",
    "details": {
      "message": "Failed to trigger recurring payment"
    }
  }
}
```
</ResponseExample>
