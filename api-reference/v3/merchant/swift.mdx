## Overview

Returns the bank details EximPe holds for a SWIFT/BIC code, in the same field names as `settlement_details` on [Create Merchant](/api-reference/v3/merchant/create#settlement). Use it to show the bank to your user before you submit, or to check a code.

```bash
curl 'https://api-pacb-uat.eximpe.com/partners/merchants/swift/?code=DBSSSGSG' \
  -H 'X-Client-ID: <client_id>' -H 'X-Client-Secret: <client_secret>' \
  -H 'X-API-Version: 3.0.0'
```

<Tip>
  You do not have to call this first. On [Create Merchant](/api-reference/v3/merchant/create#settlement) and [Update Merchant](/api-reference/v3/merchant/update), bank fields you leave out are filled from `bank_swift_code` in the same way.
</Tip>

## Query parameters

| Name | Type | Required | Description |
|---|---|---|---|
| code | string | Yes | SWIFT/BIC code. 8 or 11 uppercase letters and digits, e.g. `DBSSSGSG`. |

## The response

| Name | Type | Description |
|---|---|---|
| bank_name | string \| null | Name of the bank. |
| bank_branch_name | string \| null | Branch name. |
| bank_address | string \| null | Branch address. |
| bank_city | string \| null | Branch city. |
| bank_pincode | string \| null | Branch postal code. |
| bank_country | string \| null | Branch country, in the spelling listed by [Get Merchant Options](/api-reference/v3/merchant/options#countries). `null` when the bank's country is not one of the supported countries. |
| bank_swift_code | string | The code you looked up. |

A field is `null` when EximPe holds no value for it. `bank_state` is not returned; you always send it yourself.

```json 200 OK
{
  "success": true,
  "message": "Bank details retrieved successfully",
```

```json 400 Not found
{

  "error": {
    "code": "ERR_MERCHANT_019",
    "message": "Bank details could not be found for bank_swift_code",
```

</CodeGroup>

## Errors

| HTTP | Cause | `code` | What to do |
|---|---|---|---|
| `400` | `code` is missing or malformed, or no bank details were found for it | `ERR_MERCHANT_019` | Check the code. If it is correct, send every bank field yourself on [Create Merchant](/api-reference/v3/merchant/create#settlement). |
| `401` | Missing or invalid credentials | `ERR_AUTH_000`, `ERR_AUTH_001` | Check `X-Client-ID` and `X-Client-Secret`. |
| `403` | Your account is not a PSP | `ERR_AUTH_003` | Only PSPs can manage sub-merchants. |
| `403` | Your account is a PSP, but not set up for import collections | `ERR_MERCHANT_017` | Contact EximPe. |
