## Overview

Returns one of your sub-merchants: every field you sent when you created or last edited it, its current status, and — when EximPe has sent it back or rejected it — the reasons why.

## Path Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| merchant_id | string | Yes | The sub-merchant's ID, as returned by [Create Merchant](/api-reference/v3/merchant/create), e.g. `6182929449`. |

## Response

`data` has the same shape as the [Create Merchant](/api-reference/v3/merchant/create#response) response.

| Name | Type | Description |
|---|---|---|
| id | string | The sub-merchant's merchant ID. |
| status | string | `PENDING`, `IN_REVIEW`, `CHANGES_REQUESTED`, `APPROVED` or `REJECTED`. See [Statuses](/api-reference/v3/merchant/create#statuses). |
| legal_name, brand_name, email, phone_number | string | As sent. |
| global_company | object | Company, business and address details, as sent. Dropdown values are returned in their listed spelling. |
| settlement_details | object | Bank details, as sent. The bank account number is returned in full. |
| settlement_currency | string \| null | ISO code of the currency the sub-merchant is paid out in, which follows your own settlement account. |
| beneficial_owners | array | Each owner, as sent, with its `id`. Every owner carries every owner field; fields that do not apply to its type are `null`, so `identify_number` (a company owner's registration number) is `null` for an `INDIVIDUAL` owner. Empty when no owners are stored, which is always the case when your account does not collect under EximPe's own licence. |
| changes_requested_reason | string \| null | EximPe's reason when the status is `CHANGES_REQUESTED`; otherwise `null`. |
| section_reasons | array | When the status is `CHANGES_REQUESTED`, one `{ "section", "reason" }` entry per part of the application that needs changes; otherwise empty. See [Sections](/api-reference/v3/merchant/options#sections). |
| reject_reason | string \| null | EximPe's reason when the status is `REJECTED`; otherwise `null`. |
| created_at | string | Time of creation, UTC, ISO 8601 without a timezone suffix. |
| updated_at | string | Time of the last change, UTC, ISO 8601 without a timezone suffix. |

## Errors

| Status | `error.code` | When | `details` |
|---|---|---|---|
| `401` | `ERR_AUTH_000`, `ERR_AUTH_001` | `X-Client-ID` or `X-Client-Secret` is missing or wrong | `{"authentication": "Missing credentials."}` or `{"authentication": "Invalid credentials."}` |
| `403` | `ERR_AUTH_003` | Your account is not a PSP | `{}`. Only PSPs can manage sub-merchants |
| `403` | `ERR_MERCHANT_017` | Your account is a PSP, but not set up for import collections | `{}`. Contact EximPe |
| `404` | `ERR_MERCHANT_016` | No sub-merchant with this ID belongs to you, or it has been deleted | `{}`. Check the ID. The same answer is given whether the ID does not exist or belongs to someone else |
