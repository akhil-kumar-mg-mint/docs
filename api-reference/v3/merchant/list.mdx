---

## Overview

Returns the sub-merchants you have onboarded, newest first. Each entry has the same shape as [Get Merchant](/api-reference/v3/merchant/get). Deleted sub-merchants are not listed.

```bash
curl 'https://api-pacb-uat.eximpe.com/partners/merchants/?page=1&page_size=50&search=Acme' \
  -H 'X-Client-ID: <client_id>' -H 'X-Client-Secret: <client_secret>' \
  -H 'X-API-Version: 3.0.0'
```

## Query parameters

| Name | Type | Required | Description |
|---|---|---|---|
| page | integer | No | Page number. Default `1`. |
| page_size | integer | No | Results per page. Default `250`, maximum `1000`. |
| search | string | No | Matches legal name, brand name, registration number or tax ID. |
| ordering | string | No | `created_at` or `-created_at`. Default `-created_at`. |

## The response

`data` is a page:

| Name | Type | Description |
|---|---|---|
| count | integer | Total number of matching sub-merchants. |
| page | integer | This page's number. |
| page_size | integer | Results per page. |
| next | string \| null | URL of the next page, or `null` on the last page. |
| previous | string \| null | URL of the previous page, or `null` on the first page. |
| results | array | The sub-merchants on this page. Each has every field described in [Get Merchant](/api-reference/v3/merchant/get#the-response). |

## Errors

| HTTP | Cause | `code` | What to do |
|---|---|---|---|
| `401` | Missing or invalid credentials | `ERR_AUTH_000`, `ERR_AUTH_001` | Check `X-Client-ID` and `X-Client-Secret`. |
| `403` | Your account is not a PSP | `ERR_AUTH_003` | Only PSPs can manage sub-merchants. |
| `403` | Your account is a PSP, but not set up for import collections | `ERR_MERCHANT_017` | Contact EximPe. |
