## Overview

Every HS code you send must be one EximPe recognises. This endpoint searches that list by code or by description. Send the `value` of the code you pick:

- **Direct merchants:** in `hs_code` on [Create Order](/api-reference/v3/order/create).
- **PSPs:** in `global_company.hs_codes` on [Create Merchant](/api-reference/v3/merchant/create) or [Update Merchant](/api-reference/v3/merchant/update). A sub-merchant with a goods category must declare at least one.

<Note>
  **Who can call this.** Direct merchants and PSPs set up for import collections. Any other account gets a `403`.
</Note>

## Query Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| search | string | No | Text to match against the code and its description, e.g. `8471` or `laptop`. Leave it out to page through every code. |
| page | integer | No | Page number. Default `1`. |
| page_size | integer | No | Results per page. Default `250`, maximum `1000`. |

## Response

`data` is a page, with the same paging fields as [List Merchants](/api-reference/v3/merchant/list#response). Each result is one HS code:

| Name | Type | Description |
|---|---|---|
| id | integer | EximPe's ID for the code. |
| value | string | The HS code. Send this in `hs_codes`. |
| description | string | What the code covers. |
| policy | string | The import policy that applies to the code. Empty when none is recorded. |

## Errors

| Status | `error.code` | When | `details` |
|---|---|---|---|
| `401` | `ERR_AUTH_000`, `ERR_AUTH_001` | `X-Client-ID` or `X-Client-Secret` is missing or wrong | `{"authentication": "Missing credentials."}` or `{"authentication": "Invalid credentials."}` |
| `403` | `ERR_AUTH_003` | Your account is neither a direct merchant nor a PSP | `{"authentication": "This endpoint is only accessible to PSP merchants."}` |
| `403` | `ERR_MERCHANT_017` | Your account is a PSP, but not set up for import collections | `{}`. Contact EximPe |
| `403` | `ERR_MERCHANT_ACCOUNT_002` | Your account is inactive | `{"authentication": "Merchant account is inactive."}`. Contact EximPe |
| `403` | `ERR_MERCHANT_ACCOUNT_003` | Your account is suspended or closed | `{"merchant_account": "Merchant account is suspended."}` or `{"merchant_account": "Merchant account is closed."}`. Contact EximPe |
