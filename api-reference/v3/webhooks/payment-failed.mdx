## Event Overview

**Event Type**: `PAYMENT_FAILED`  
**Category**: Payment  
**Description**: Payment transaction has failed

This webhook is triggered when a customer's payment attempt fails through EximPe. It is also sent when an attempt expires without an outcome, and when a hosted checkout ends with no payment attempted, in which case `extended_status` is `NOT_ATTEMPTED`.

## Field Specifications

<Tabs>
  <Tab title="Root Level Fields">
    <ParamField path="event_type" type="string" required>
      Always `"PAYMENT_FAILED"` for this webhook event
    </ParamField>

    <ParamField path="event_time" type="string" required>
      UTC, no timezone suffix, e.g. `"2026-02-15T16:53:15.123456"`. Parse tolerantly — fractional seconds can be absent.
    </ParamField>

    <ParamField path="version" type="string" required>
      API version of your account, e.g. `"3.0.0"`
    </ParamField>

    <ParamField path="sequence_number" type="string" required>
      Unique ID of this event (a UUID, not an ordering counter). A retry resends the same value; use it to de-duplicate.

      **Example**: `"e40552bf-ed12-4f35-9a97-162d97e6fa34"`
    </ParamField>

    <ParamField path="data" type="object" required>
      Event-specific data payload containing failed payment transaction details
    </ParamField>
  </Tab>

  <Tab title="Data Object Fields">
    <ParamField path="data.status" type="string" required>
      Payment status (FAILED for failed payments)
      
      **Example**: `"FAILED"`
    </ParamField>

    <ParamField path="data.message" type="string" required>
      Failure reason or message
      
      **Example**: `"Cancelled by user"`
    </ParamField>

    <ParamField path="data.mop_type" type="string" required>
      Method of payment type
      
      **Example**: `"UPI"`
    </ParamField>

    <ParamField path="data.order_id" type="string" required>
      Order ID
      
      **Example**: `"OD3376378679"`
    </ParamField>

    <ParamField path="data.link_id" type="string">
      ID of the payment link this payment was made through — the `link_id` that [Create Payment Link](/api-reference/v3/payment-link/create) returned. `null` when the payment was not made through a payment link; the key is always present. A buyer can try a link more than once, so several payments can carry the same `link_id`, each with its own `payment_id`. On some accounts `payment_id` and `link_id` can be the same value. Match the payment to your link on `link_id`; reconcile it by `payment_id`. Where each try is a payment of its own, a try that fails does not send this event; it arrives once, for the link itself, when the link closes without being paid, with `payment_id` equal to `link_id`.

      **Example**: `"PR4829301756"`
    </ParamField>

    <ParamField path="data.payment_id" type="string" required>
      Payment ID
      
      **Example**: `"PR6938527534"`
    </ParamField>

    <ParamField path="data.bank_ref_num" type="string">
      Bank reference number. `null` when the attempt never reached the bank, such as an expiry or a checkout that ended with no attempt
      
      **Example**: `"OD3376378679-PR6938527534"`
    </ParamField>

    <ParamField path="data.amount" type="number" required>
      Payment amount

      **Example**: `1000`
    </ParamField>

    <ParamField path="data.extended_status" type="string" required>
      Detailed status code for the failure. One of `FAILED`, `USER_DROPPED`, `NOT_ATTEMPTED`, `EXPIRED`, `TERMINATED`, `CANCELLED`, `VOID`, `BOUNCED`, `AUTHORIZATION_FAILED`, `GATEWAY_DECLINED`, `GATEWAY_ERROR` or `AUTO_REFUNDED`. New values may be added, so handle an unknown one gracefully.

      **Example**: `"USER_DROPPED"`
    </ParamField>

    <ParamField path="data.payment_message" type="string">
      Additional processor-level message; may be null
    </ParamField>

    <ParamField path="data.payment_completed_at" type="string" required>
      ISO 8601 payment completion timestamp
      
      **Example**: `"2026-02-15T16:53:10.000000Z"`
    </ParamField>

    <ParamField path="data.utr" type="string">
      UTR of the payment (if any); may be empty or null
    </ParamField>

    <ParamField path="data.virtual_account_id" type="string">
      Virtual account ID, if the payment came in through a virtual account; otherwise null.
    </ParamField>

    <ParamField path="data.subscription_id" type="string">
      Subscription ID if this payment is linked to a subscription mandate; otherwise null
    </ParamField>

    <ParamField path="data.merchant_reference_id" type="string" required>
      Your reference ID for the order

      **Example**: `"S2SICR1QPJ"`
    </ParamField>
  </Tab>
</Tabs>
