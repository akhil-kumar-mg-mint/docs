## Event Overview

**Event Type**: `MERCHANT_APPROVED`  
**Category**: Onboarding  
**Description**: Sub-merchant account has been approved and activated

This webhook is triggered when a sub-merchant account is approved and can start collecting payments through EximPe. Only sub-merchant approvals send it, and it is delivered to the parent merchant's webhook URL. A direct merchant's own approval sends nothing.

      Event-specific data payload containing merchant approval details
    </ParamField>
  </Tab>

    <ParamField path="data.legal_name" type="string" required>

      **Example**: `"TechStore Solutions Private Limited"`

    <ParamField path="data.trade_name" type="string" required>

      **Example**: `"TechStore Online"`
