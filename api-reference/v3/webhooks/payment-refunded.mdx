## Event Overview

**Event Type**: `PAYMENT_REFUNDED`  
**Category**: Payment  
**Description**: Payment has been refunded

This webhook is triggered when a payment is refunded to the customer through EximPe.

## Payload Schema

<CodeGroup>

```json Example Payload

    "data": {
        "refunds": [

}
```

## Field Specifications

<Tabs>
  <Tab title="Root Level Fields">
    <ParamField path="event_type" type="string" required>
      Always `"PAYMENT_REFUNDED"` for this webhook event
    </ParamField>

    <ParamField path="event_time" type="string" required>
      Timestamp when the event occurred in ISO 8601 format
      
      **Example**: `"2026-02-15T16:53:15.481203"`
    </ParamField>

    <ParamField path="version" type="string" required>
      Webhook payload version, the API version of your account (for example "3.0.0")
    </ParamField>

    <ParamField path="sequence_number" type="string" required>
      Unique identifier for the event instance
      
      **Example**: `"e40552bf-ed12-4f35-9a97-162d97e6fa34"`
    </ParamField>

    <ParamField path="data" type="object" required>
      Event-specific data payload containing refund details
    </ParamField>
  </Tab>

  <Tab title="Data Object Fields">
    <ParamField path="data.refunds" type="array" required>
      Array of refund objects containing the refund information
    </ParamField>

    <ParamField path="data.refunds[].order_id" type="string" required>
      Order ID associated with the refund
      
      **Example**: `"OD6085456489"`
    </ParamField>

    <ParamField path="data.refunds[].order_reference_id" type="string">
      Your reference ID for the order, as sent when it was created. `null` when the order has none.

      **Example**: `"S2SICR1QPJ"`
    </ParamField>

    <ParamField path="data.refunds[].refund_id" type="string" required>
      Unique refund identifier
      
      **Example**: `"RF2684785771"`
    </ParamField>

    <ParamField path="data.refunds[].refund_reference_id" type="string">
      Your reference for the refund — the `reference_id` sent when it was created, or the one we generated when none was sent. `null` when the refund has none.

      **Example**: `"RF-2026-0044"`
    </ParamField>

    <ParamField path="data.refunds[].payment_id" type="string" required>
      Original payment ID that was refunded

      **Example**: `"PR7485664995"`
    </ParamField>

    <ParamField path="data.refunds[].refund_amount" type="number" required>
      Refund amount
      
      **Example**: `1000`
    </ParamField>

    <ParamField path="data.refunds[].comments" type="string">
      Human-readable note describing the refund outcome

      **Example**: `"Refund processed successfully"`
    </ParamField>

    <ParamField path="data.refunds[].bank_arn" type="string">
      Bank ARN (Acquirer Reference Number) - may be null
      
      **Example**: `"74523129087"`
    </ParamField>

    <ParamField path="data.refunds[].refund_completed_at" type="string">
      Timestamp when the refund completed - `null` when the completion time is not known

      **Example**: `"2026-02-15T16:53:15.123456"`
    </ParamField>
  </Tab>
</Tabs>
